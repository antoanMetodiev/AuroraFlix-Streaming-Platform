## 1. Направено (14.10.2026)

  му сервираше `lang="en"` и английски заглавия. Сега `resolveInitialLocale` (app/layout.tsx)
  връща `bg`, освен ако браузърът изрично иска `en` без `bg`.
- [x] **`/robots.txt`** (app/robots.ts) — всичко публично е отворено; `/api/`, `/account`,
  `/sign-in`, `/sign-up`, `/friends`, `/watchlist`, `/playlists` са забранени.
- [x] **`/sitemap.xml`** (app/sitemap.ts) — ~5535 адреса: начало, /movies, /series, жанрове,
  всички филми и сериали + постери.
- [x] **Метаданни** (lib/seo.ts) — БГ заглавия и описания, keywords (кирилица + латиница),
  canonical, Open Graph `bg_BG`; филтрирани списъци → `noindex, follow`; not-found → `noindex`.
- [x] **JSON-LD** — WebSite + Organization (layout), Movie / TVSeries на детайлните страници.
  `aggregateRating` нарочно липсва (нямаме собствени оценки).
- [x] **H1** — начална страница (`components/home/seo-intro.tsx` + линкове към жанрове),
  списъци и жанрове („Онлайн филми“, „Екшън филми“…).
- [x] **Footer** — „Филми“, „Сериали“, „Жанрове“ и т.н. са истински `<a>` линкове.
- [x] **Google Search Console** — Domain property `auroraflix.cloud` (TXT в Cloudflare DNS),
  подаден `sitemap.xml`, заявка за индексиране на `/`, `/movies`, `/series`.

## 3. Следващи идеи (по приоритет)

### Бързи
- [ ] **Bing Webmaster Tools** — импорт от Search Console (покрива и DuckDuckGo, Yahoo).
- [ ] **Социални иконки във footer-а** са `href="#"` — или реални профили, или да се махнат.
- [ ] **Open Graph изображение по подразбиране** (1200×630) за началото и списъците — по-хубав
  преглед при споделяне във Facebook / Viber / Messenger.
- [ ] **`alt` текстове** на постерите — „Заглавие (година) – постер“, ако някъде липсват.
- [ ] Footer линкът „Жанрове“ води към `/movies/genres/Action` — по-добре отделна страница
  `/genres` със списък на всички жанрове.

### Съдържание (най-голям ефект с времето)
- [ ] **Български заглавия и описания** на филмите/сериалите, където ги нямаме — хората търсят
  „Хари Потър“, не само „Harry Potter“.
- [ ] **Страници по година** (`/movies/year/2025`) и „Нови филми 2026“ — популярни заявки.
- [ ] **Страници на актьори** — „филми с Леонардо ди Каприо“.
- [ ] **„Подобни филми“** на детайлната страница — вътрешни линкове, Google обхожда по-дълбоко.
- [ ] Кратък уникален текст (2–3 изречения) в началото на всяка жанрова страница.
- [ ] Сериали: страници/секции по сезони и епизоди с „S01E01 с БГ субтитри“.

### Технически
- [ ] `hreflang` — само ако някога направим отделни адреси за английски (`/en/...`).
- [ ] Sitemap index (разделяне на филми / сериали), ако каталогът мине ~40–50 хил. адреса.
- [ ] `lastModified` в sitemap-а от реални дати на обновяване, а не текущото време.
- [ ] Скорост на мобилни — PageSpeed Insights за `/`, `/movies`, детайлна страница.

### Външни линкове (backlinks)
- [ ] Профили във Facebook / Instagram / TikTok / YouTube с линк към сайта.
- [ ] Публикации във форуми и групи (филмови групи във Facebook, Reddit r/bulgaria и др.).
- [ ] Страницата за изтегляне на мобилното приложение (APK) — също носи линкове и търсения.

## 4. Полезни проверки

```bash
# Живи ли са robots и sitemap
curl -s -o /dev/null -w "%{http_code}\n" https://auroraflix.cloud/robots.txt
curl -s https://auroraflix.cloud/sitemap.xml | grep -o "<loc>" | wc -l

# Какво вижда Googlebot (език, заглавие, canonical)
curl -s -A "Googlebot" https://auroraflix.cloud/ | grep -oE '<html[^>]*>|<title>[^<]*</title>|rel="canonical"[^>]*>'
```

- Rich Results Test (JSON-LD): https://search.google.com/test/rich-results
- PageSpeed Insights: https://pagespeed.web.dev/
- Search Console: https://search.google.com/search-console
- Bing Webmaster Tools: https://www.bing.com/webmasters

**Реалистично очакване:** „онлайн филми“ е силно конкурентна дума. Първо идва трафик по
конкретни заглавия („[филм] онлайн бг субтитри“), а общите думи искат месеци и външни линкове.
